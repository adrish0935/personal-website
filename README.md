> Minimalist personal portfolio of **Adrish**, an Electronics Engineering student at **Haldia Institute of Technology (HIT)** (Class of 2026 – 2030) specializing in **VLSI Design, RISC-V Microarchitecture, and Silicon ASIC Flows**.

Built with [Next.js 15](https://nextjs.org), [React 19](https://react.dev), and [Tailwind CSS](https://tailwindcss.com), following a clean, monochrome editorial technical paper aesthetic inspired by DEVFOLIO.

---

## ⚡ Key Highlights

- **Aesthetic**: Minimalist monochrome palette (`neutral-950`, `neutral-900`, `neutral-800`, `neutral-100`).
- **Focus Areas**:
  - `01 // Digital RTL`: Synthesizable SystemVerilog datapaths & forwarding logic.
  - `02 // Microarchitecture`: 5-Stage pipelined RISC-V RV32I processor core.
  - `03 // ASIC & Physical Design`: OpenROAD SkyWater 130nm RTL-to-GDSII flow.
- **Academic Foundation**: Coursework and hardware initiatives at **Haldia Institute of Technology (HIT)**.
- **Code Structure**: Strict adherence to the Single Responsibility Principle (SRP), with all component files under 150 lines.

## 🚀 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run the development server
```bash
npm run dev
# or on Windows PowerShell:
npm.cmd run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for production
```bash
npm run build
npm start
```
